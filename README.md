## Aim
To implement Stack and Queue using arrays and linked lists in C++, and maintain the programs using Git and GitHub.

## Objectives
- Understand Stack and Queue operations.
- Implement Stack using an array.
- Implement Queue using an array.
- Implement Stack using a linked list.
- Implement Queue using a linked list.
- Learn Git version control and GitHub repository management.

## Programs
1. Stack using Array
2. Queue using Array
3. Stack using Linked List
4. Queue using Linked List

## Concepts
- **Stack:** LIFO (Last In, First Out).
- **Queue:** FIFO (First In, First Out).
- **Array:** Stores elements in a fixed-size collection.
- **Linked List:** Stores dynamically allocated nodes connected using pointers.

## Software Requirements
- Visual Studio Code
- G++ C++ compiler
- Git
- GitHub account

## How to Compile and Run

Open the MSYS2 UCRT64 terminal and navigate to the required folder.

### Stack using Array
```bash
cd Stack
g++ Stack_using_Array.cpp -o stack_array.exe
./stack_array.exe
```

### Stack using Linked List
```bash
g++ Stack_using_LinkedList.cpp -o stack_linkedlist.exe
./stack_linkedlist.exe
```

### Queue using Array
```bash
cd ../Queue
g++ Queue_using_Array.cpp -o queue_array.exe
./queue_array.exe
```

### Queue using Linked List
```bash
g++ Queue_using_LinkedList.cpp -o queue_linkedlist.exe
./queue_linkedlist.exe
```
